# @openai/maxcode-responses-api-proxy

<p align="center"><code>npm i -g @openai/maxcode-responses-api-proxy</code> to install <code>maxcode-responses-api-proxy</code></p>

This package distributes the prebuilt [Maxcode Responses API proxy binary](https://github.com/RavaniRoshan/maxcode-engine/tree/main/maxcode-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/maxcode-responses-api-proxy.js --help
```

Refer to [`maxcode-rs/responses-api-proxy/README.md`](https://github.com/RavaniRoshan/maxcode-engine/blob/main/maxcode-rs/responses-api-proxy/README.md) for detailed documentation.
